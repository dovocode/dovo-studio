# Accessibility

Open **Settings → Appearance → Accessibility** on desktop or mobile. These choices are saved on that
device.

- **Status colors** offers **Normal** (the default green/red palette) and **GitHub colorblind**
  (blue/orange) for status indicators and diff additions/deletions, including PR and pipeline
  states. States retain their icons and text, and diffs show `+`/`−` markers. The setting does not
  recolor artifact contents or syntax tokens in code. Custom code themes keep the selected status
  palette.
- **Higher contrast** independently strengthens interface text, borders, controls and the selected
  status palette on neutral surfaces. Code themes remain separate; diff line numbers become stronger
  too. Turning it off restores the normal contrast for the selected palette.
- **Animations → Reduce** reduces interface animations and conversation jumps. **System** follows
  the operating system’s Reduce motion preference. On mobile, it also removes animated worktree
  progress and swipe settling effects.

Desktop text size and fonts are in Appearance. Mobile follows the phone’s system text size; settings
stack controls vertically for larger text. Keyboard focus has a visible outline, including in
Windows contrast themes.
