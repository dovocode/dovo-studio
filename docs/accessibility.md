# Accessibility

Open **Settings → Appearance → Accessibility** on desktop or mobile. These choices are saved on that
device.

- **Status colors → GitHub colorblind** is the default blue/orange palette for status indicators and
  diff additions/deletions, including PR and pipeline states. The **higher contrast** variant uses
  GitHub’s stronger colors. Light mode already uses those stronger colors for readability. Thread
  and PR states retain their icons and text, and diffs show `+`/`−` markers. The setting does not
  recolor artifact contents or syntax tokens in code. Custom code themes keep the same
  addition/deletion colors as built-in themes.
- **Higher contrast** uses stronger interface text, borders and controls on neutral surfaces. Code
  themes remain separate; diff line numbers become stronger too.
- **Animations → Reduce** reduces interface animations and conversation jumps. **System** follows
  the operating system’s Reduce motion preference. On mobile, it also removes animated worktree
  progress and swipe settling effects.

Desktop text size and fonts are in Appearance. Mobile follows the phone’s system text size; settings
stack controls vertically for larger text. Keyboard focus has a visible outline, including in
Windows contrast themes.
