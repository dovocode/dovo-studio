Settings opens in a floating panel. The sidebar and panes share the updated layout across Threads, Browser, Terminals, Unified Workspace, Pull Requests, Issues, Jira, and Bots.
Use tabs for thread tools, dock a terminal on the right, and open desktop Chrome DevTools from the tool picker. Unified Home and Terminals show tools for their current context.
Browser tabs stay in the sidebar. New browser tab threads default to No Project on the tab’s computer.
