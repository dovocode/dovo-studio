category: Changed
clients: desktop, web
---

Settings opens in a floating panel. Thread tools use tabs, and terminals can dock on the right.
Browser, Unified Workspace, and Terminals keep item navigation in the sidebar. Open Chrome DevTools
for a local page from the desktop right-pane tool picker. Panes sit on a darker canvas, and message
bubbles and the composer stand out from the pane. Messages align with the composer. The Files tab
and terminal headers use one row, and the thread tools menu no longer shows a tooltip over its own
labels. New layouts start with a narrower thread list and wider tools pane. The extra frame around
terminals is gone. Sidebar and pane spacing match Threads. Unified Home and Terminals offer tools
for the current workspace. New browser tab threads default to No Project on the tab’s computer. The
main navigation icons sit on the same background as the workspace sidebar. Pull requests, Issues,
Jira and Bots use the same sidebar and pane layout as Threads.
