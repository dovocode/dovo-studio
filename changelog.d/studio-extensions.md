Install Studio extensions that add tool actions, MCP App views, settings, and dashboard tiles.
Agents can validate and stage extension manifests for review. Allow agents to install their own
drafts with a per-computer setting. Extension settings and dashboard tiles can use Studio
components, bind tool results to charts and tables, and show custom diagrams with a Studio component
fallback.

Open extension views receive changes promptly and keep compatible unsaved settings edits. Agents can
read manifests authored in their thread. Custom components accept optional JSON props with a
fallback for unsupported renderers.

Studio confirms the exact draft revision before installation. Agents can replace only their own
pending drafts. Settings editors show concurrent changes to the same field before saving. Open MCP
Apps and standalone tool results stay in place while the installed contribution stays the same.

Agents can compose Studio extension views with a typed UI SDK. The agent catalog also provides the
full manifest JSON Schema for use in other projects.

Browse the curated Extension Marketplace, choose local sources, and install a reviewed release.
Agents can find and stage marketplace packages. Packages can include a dashboard template.
