Inter 4.1 static TrueType faces from the
[official release](https://github.com/rsms/inter/releases/tag/v4.1). These unmodified files are
embedded in the GPUI executable. Regular, medium, semibold, bold and italic faces cover workbench
text and Markdown without relying on the host's UI fonts.
